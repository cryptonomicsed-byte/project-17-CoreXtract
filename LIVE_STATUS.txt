    ├── App.svelte - Main component

Adding Features
  1. Define types in packages/shared/types.ts
  2. Create service in packages/backend/src/services/
  3. Create routes in packages/backend/src/routes/
  4. Register routes in packages/backend/src/index.ts

Testing Endpoints
  Use curl, Postman, or Thunder Client
